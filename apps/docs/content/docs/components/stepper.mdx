## Installation

```npm
npx shadcn@latest add https://liquidcomponents.xyz/r/liquid-stepper.json
```

## Usage

```tsx
import { LiquidStepper } from "@/components/ui/liquid-stepper"

export function Guests() {
  const [guests, setGuests] = useState(2)
  return <LiquidStepper value={guests} onValueChange={setGuests} min={0} max={10} aria-label="Guests" />
}
```

Hold a button and it repeats. The value pops on every change, and the buttons disable at `min` and `max`. Use `step` for bigger jumps, `format` to label the value and `showValue={false}` for the compact iOS form.

## API

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number` | none |
| `defaultValue` | `number` | `0` |
| `onValueChange` | `(value: number) => void` | none |
| `min` | `number` | `-Infinity` |
| `max` | `number` | `Infinity` |
| `step` | `number` | `1` |
| `format` | `(value: number) => ReactNode` | none |
| `showValue` | `boolean` | `true` |
| `disabled` | `boolean` | `false` |
| `aria-label` | `string` | `"Value"` |

## Keyboard

`Tab` moves between the two buttons, and `Enter` or `Space` steps once. Holding the pointer down repeats.
