---
title: AI skill
description: Teach your AI to build with Liquid UI.
---

The skill tells your AI which component fits, where glass works and what to check, so the result doesn't look generated.

## Install

```npm
npx shadcn@latest add https://liquidcomponents.xyz/r/liquid-ui-skill.json
```

Or with the skills CLI: `npx skills add vwakesahu/liquid-components`.

## Use it

Ask for a screen, like "a photo library with a tab bar and a share drawer".
