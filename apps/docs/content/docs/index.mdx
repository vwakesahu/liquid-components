## Open code

Components install as source through the shadcn CLI, so the code lands in your project and there's no Liquid UI runtime to depend on. You get the component, its hooks and its utilities, and they're yours to change.

```npm
npx shadcn@latest add https://liquidcomponents.xyz/r/liquid-switch.json
```

## Built on Radix

Radix is the set of headless primitives underneath, it owns the semantics, focus and keyboard behaviour. Liquid UI adds the material, the refraction, the pointer physics and the spring motion on top. Start with [installation](/docs/installation), or read how the [material and motion](/docs/foundations/material) work.

If it helps your project, [star Liquid UI on GitHub](https://github.com/vwakesahu/liquid-components).
